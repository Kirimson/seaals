Seal-y Examples

Endpoint Description Example
/seal Returns a random Seal
/seal?tag={tag} Returns a random Seal with a specified tag.
File types are also tags!
/seal/says/{text} Returns a random Seal saying {text}
/seal/says/{text}?fontColour=colour&fontSize={size} Returns a random Seal saying {text} in {colour} and size {size}
/seal?filter={filter} Returns a random Seal with {filter} applied
